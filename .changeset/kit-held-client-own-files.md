A client held to a ceiling (`MCP_CLIENT_MAX_ACCESS`) may now fetch from `GET /files/outbox/<path>` the files its own calls handed back, and nothing else. Before, it was refused every file, so a client allowed only `read` tools could call a tool that saves an e-mail attachment, an invoice archive or a downloaded document and links it, and then could not fetch the very file its call produced. A file counts as its own when the call's code saved it through the kit's outbox writer (`saveToOutbox`, `noteHandedBack`) and the call succeeded; a link a result merely carries does not count, so a tool that echoes a link it was given opens nothing. The server records the file as it was written (device, inode, size, modification and change time), so a file another client's call puts at the same path, even while the first call is still running, is refused, and so is the file after a later change of its mode, owner, ACL or label, or a hard link to it. Every other request from such a client is still the same 403: any upload, another client's file, a guessed path, a path out of the outbox, and its own path once another file or a link is there. Clients that share a token are one client to the server, so they also share each other's saved files.

The records are kept in memory, at most 10,000 per client, for `MCP_HTTP_FILES_HELD_MAX_AGE_MIN` minutes, a new setting that follows `MCP_HTTP_FILES_MAX_AGE_MIN` when it is unset, or 24 hours when both are, so an outbox that keeps its files for 30 days can keep the records as long without a sweep deleting anything. A restart forgets them: a fetch after one is refused, and calling the tool again brings the file. The 403's words now say so. A client with no ceiling is served exactly as before.

`writeFileAtomicWithStats` writes a file as `writeFileAtomic` does and also answers the written file's stats, and `noteHandedBack` takes them as an optional third argument; a server's own outbox writer that passes them makes its files' records exact even when another call writes the same name at the same moment. Without them, `noteHandedBack` reads the file at the path the moment it is called.
